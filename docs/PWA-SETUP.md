# PWA Setup Guide

Your KS Sports Ladder app is now configured as a **Progressive Web App (PWA)**! This means users can install it directly from their browser without going through app stores.

## ✅ What's Been Configured

1. **Service Worker** - Automatically generated by next-pwa
2. **App Manifest** - Defines app name, colors, and icons
3. **Icons** - Placeholder SVG icons (you should replace with PNG)
4. **Metadata** - PWA-specific meta tags in layout.tsx

## 📱 How Users Will Install

### On Mobile (iOS/Android):
1. Visit your website in Safari (iOS) or Chrome (Android)
2. Look for "Add to Home Screen" prompt or banner
3. Tap "Add" to install
4. App icon appears on home screen like a native app

### On Desktop (Chrome/Edge):
1. Visit your website
2. Look for install icon in address bar (⊕ or ⬇)
3. Click "Install"
4. App opens in standalone window

## 🎨 Customizing Icons

The current icons are **placeholder SVGs with a trophy emoji**. For production:

### Option 1: Use the Browser Generator
1. Open `http://localhost:3000/generate-icons.html` in dev mode
2. Click the download buttons to get PNG files
3. Replace the SVG files in `/public/`

### Option 2: Design Custom Icons
1. Create your logo in 512x512px (PNG format recommended)
2. Use [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator) or similar
3. Replace files in `/public/`:
   - `icon-192x192.png` (or .svg)
   - `icon-512x512.png` (or .svg)
   - `icon.svg` (maskable version)
   - `favicon.svg`

### Option 3: Convert SVG to PNG
```bash
# Using ImageMagick (if installed)
magick icon.svg -resize 192x192 icon-192x192.png
magick icon.svg -resize 512x512 icon-512x512.png
```

Or use online tools like:
- https://cloudconvert.com/svg-to-png
- https://www.pwabuilder.com/imageGenerator

## 🔧 Configuration Files

### `public/manifest.json`
Defines app metadata, theme colors, and capabilities:
- **name**: "KS Sports Ladder" (full app name)
- **short_name**: "Sports Ladder" (shown under icon)
- **theme_color**: "#2563eb" (blue from your design)
- **background_color**: "#ffffff" (splash screen)
- **display**: "standalone" (looks like native app)
- **shortcuts**: Quick actions (Challenges, Matches, Ladders)

### `next.config.mjs`
PWA plugin configuration:
- **dest**: "public" (where service worker is generated)
- **register**: true (auto-register service worker)
- **skipWaiting**: true (update immediately)
- **disable**: true in development (no caching during dev)

### `src/app/layout.tsx`
Metadata for PWA support:
- Manifest link
- Apple Web App tags
- Viewport settings
- Theme color

## 🚀 Testing Your PWA

### Local Testing:
```bash
npm run build
npm start
# Visit http://localhost:3000
```

**Note**: PWA features require HTTPS or localhost. Service workers won't register on HTTP in production.

### Production Testing (Vercel):
1. Push your changes to GitHub
2. Vercel auto-deploys with HTTPS ✅
3. Visit your site on mobile/desktop
4. Try installing the app

### PWA Audit:
Use Chrome DevTools:
1. Open DevTools (F12)
2. Go to "Lighthouse" tab
3. Select "Progressive Web App"
4. Click "Generate report"

## 🎯 Benefits Over App Stores

✅ **No fees**: Free (vs $99/year Apple + $25 Google)
✅ **No approval**: Deploy instantly (vs 1-7 day review)
✅ **No commission**: Keep 100% revenue (vs 15-30% cut)
✅ **Cross-platform**: One codebase for iOS, Android, Desktop
✅ **Instant updates**: Users get updates on refresh
✅ **SEO**: Still indexed by search engines

## ⚠️ PWA Limitations

- **iOS**: Limited background sync, no push notifications
- **Discovery**: No app store listing (rely on website traffic)
- **Storage**: Browser storage limits (not unlimited like native)
- **APIs**: Some device APIs unavailable (NFC, Bluetooth, etc.)

## 🔄 Updating Service Worker

The service worker auto-updates when you deploy. Users get updates:
- Immediately on next visit (skipWaiting: true)
- Or on next app launch/refresh

To clear cache during development:
1. Chrome DevTools → Application → Service Workers
2. Check "Update on reload"
3. Or click "Unregister" to reset
