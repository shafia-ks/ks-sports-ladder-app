# Sport Icons

Place your sport icon SVG files here with the following names:

- `badminton.svg`
- `tennis.svg`
- `squash.svg`
- `padel.svg`
- `table-tennis.svg`
- `pickleball.svg`

## Icon Requirements

- **Format**: SVG
- **Size**: 64x64px or similar (will be scaled automatically)
- **Style**: Clean, simple, recognizable
- **Colors**: Can be full color or monochrome (we can add color via CSS if needed)

## Recommended Icon Sources

1. **Flaticon** - https://www.flaticon.com/
2. **Icons8** - https://icons8.com/
3. **Noun Project** - https://thenounproject.com/
4. **Freepik** - https://www.freepik.com/

## Usage Example

```tsx
import { SportIcon } from "@/components/ui/sport-icon";

<SportIcon sport="badminton" size={32} />
```
